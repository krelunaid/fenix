# UI patterns

Seeded from Fenix craft we already enforce. **Patterns, not layouts.**

| Pack | Distilled from | Never clone |
|---|---|---|
| `water-craft` | AcquaGt / campo utility | Official 3D tank, Apple SET, mashed one-shell Home |
| `barber-corto` | Corto-level salon booking | Corto screens, raspberry, staff KPI Oggi/Nuovo |
| `library-editorial` | Bookstore / catalogo | Desk STUDIO, Tavolo/Registra, water sky |
| `premium-default-floor` | Quality floor for every compose | Optional “premium” flag — the floor is default |

Teachers taught **slot names and mode variants**. Domain hexes stay opt-in. A new brief gets the floor + the matching pack, then its own copy, mark, and IA.
